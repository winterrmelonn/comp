# ServeLog

Lots of high schools require community service hours, and students keep track of them on paper forms that get lost. ServeLog lets a student log each shift (organization, hours, supervisor), shows progress toward their school's requirement, and prints a sign-off sheet with a signature column for supervisors.

## Run

Open `index.html` in a browser. There's no build step and no server.

Your data stays in the browser's localStorage. **Download CSV** gives you a backup.

## Test

```
node test.js
```
